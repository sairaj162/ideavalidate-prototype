# Startup Idea Validator

A browser-based tool for evaluating startup ideas, reviewing market readiness, and estimating basic financial feasibility. Saved assessments are stored in the browser.

## Development

Requires Node.js and npm.

```bash
npm install
npm run dev
```

## Checks

```bash
npm test
npm run lint
npm run build
```

## Deploy to Netlify

The project uses Nitro's Netlify preset. Connect the repository to Netlify and use the build command `npm run build`; the deployment settings are in `netlify.toml`.
